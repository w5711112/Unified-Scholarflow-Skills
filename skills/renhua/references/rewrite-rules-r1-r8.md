# 改写规则 R1–R8

本合同仅在轻扫命中 R1–R8 或归属不确定时读取。每处改动必须对应一个编号；场景豁免优先，规则冲突时编号小者优先。

### R1 标点硬规则

- 破折号（——、—）一律不用。改逗号、句号，或拆句。
- 分号一律不用。两句关系紧密的并成一句，否则改句号。
- 冒号预算：全文每 300 字 ≤1 个。只保留句中规范引出（“由五个要素构成：A、B……”这类总说加分说）。提示语冒号（“核心是：”“原因如下：”）删提示语直接说内容。
- 引号预算：仅直接引语、术语首现和概念首现可用；能不用就不用。
- 顿号罗列：一个分句内 ≥3 项并列且非固定术语序列时，改变其中一项句法（加“以及/和”断开同构）。
- 中英文、中文与数字之间留一个空格；全角标点。
- 边界：改标点必须同时确认信息结构成立，不得只把分号换成句号就算完成。换标点后读一遍，断句处若出现无主语的悬空半句，按 R10 补主语或并句。

### R2 翻案腔与对称骨架

“不是 A 而是 B / 不仅仅是 A，更是 B / 与其说 A 不如说 B / 看似 A，实则 B”删前半，直接说 B；两端确实不同且都要保留时，拆成两句分述。

字面连词消失但“先压低一项、再抬高另一项”的关系仍算命中：“问题不只在……”“涉及的却是……”“构成……而非……”都在此列。仅事实纠错、范围排除和固定定义中的对称结构放行。

### R3 后置判断句

“X 是该问题的常用处理方式 / 是一种简单而有效的方法 / 是解决这一问题的途径”这类把动作先摆出、判断补在句尾的结构，改为动作叙事顺序，主语承接上文，解释用“也就是”引出。

- 原：探索与利用的平衡是特有问题。epsilon-贪婪策略是该问题的常用处理方式。
- 改：探索与利用的平衡是特有问题。它一般会通过 epsilon-贪婪策略来解决，也就是以较小概率随机探索、以较大的概率执行当前最优动作。

“也就是”同位解释是首选；只有当同位解释超过约 40 字、明显拖累主句时才拆成两句。同位解释结束后，若下一层语义跳转较大（如从动作方式转到特点评价），用句号分隔。

- 过度：……执行当前最优动作，这种策略实现简单，实践中也被广泛使用。
- 正确：……执行当前最优动作。这种策略实现简单，实践中也被广泛使用。

判断标志：谓语是“是”+ 抽象方法/方式名词，且主语是上一句刚介绍过的事物。

### R4 开场套话

“在……的今天/背景下”“随着……的发展”“近年来受到越来越广泛的关注”“当我们谈论 X”删除，直接从研究对象进入（“强化学习是机器学习的一个分支，研究……”）。

“基于你的需求”“下面将从三方面”“首先让我们了解”这类任务复述与计划声明一并删除。

**读者状态框架**：“很多人刚接触 X 时”“不少人都一头雾水”“如果你也遇到过……”会预设读者认知状态、替读者发问，删除后直接进入内容或改为平实的设问。

### R5 收尾升华与前景缝合

“综上所述”“展望未来”“必将大放异彩”“为……奠定坚实基础”“未来可期”“机遇与挑战并存”删除，或落回具体事实、适用边界、未解问题。

段中把方法观察上升为普遍道理的升华句（“这其实和产品设计一样……”）同样按本条处理。“尽管……但……”承载真实让步时保留；只制造仪式感时按本条处理。论文结论章、摘要的体裁性总结句不删。

### R6 排比与对称

- 同构三连（“提升了效率，降低了成本，优化了体验”连排）改为两项或打散；三项功能不同时保留最强项，其余另起短句，各项断言强度不变。
- 相邻两句同骨架（逗号数相同、成分同序、长度接近）打散一句；拆、并、换语序均可。
- 定义性并列允许保留，但同段同构 ≤2 处。
- work-doc 的规范编号条款和平行结构是体裁要求，不得为打散节奏而改写。

### R7 空洞修饰与夸饰

“应运而生、焕发生机、巧妙地、强大能力、坚实基础、关键所在、相辅相成、日益凸显、深刻的（影响）、深远的（意义）、不可磨灭、前所未有、至关重要、毋庸置疑、令人瞩目、令人深思、具有重要意义、发挥着关键作用”还原为具体动作或删除。

- “价值函数应运而生”→“为刻画这一目标，引入价值函数”。
- “具有重要意义”→说清楚什么意义，说不出就删。
- 戏剧化揭露修辞（“揭开面纱/戳穿本质/撕开伪装”）一律删除。

**渲染阅读体验类**的判定标准是：句子在陈述对象事实，还是在渲染读者的阅读/学习体验？后者删，留事实。“一眼就能看懂、就等于掌握了、轻松很多、看完就能上手、学完就会、是新手入门的首选、最经典的、必知、终极目标、真正的、缺一不可、拉到了新高度、行业标配”均按此判断。

- 原：用生活场景类比一眼就能看懂。
- 改：可以用生活场景类比。
- 原：理解了这三个要素，就等于掌握了强化学习的骨架。
- 改：强化学习的体系由三个核心部分组成。

朴实是各语体共同的底色；博客等相对口语的语体也不得用这些词渲染体验或抬高内容价值。

### R8 无源引用

“研究表明/有学者指出/据相关调查/数据显示/业内人士认为”按以下三种处理选一：

1. 去掉铺垫后论断可独立成立：删铺垫留论断；
2. 论断依赖该来源：保留原句并在「需补信息」标注待补出处；
3. 用户要求保留结构：占位说明“有研究认为……此处未给出处”。

不得虚构来源、机构、年份、DOI、链接。原文引用物一律不动。
