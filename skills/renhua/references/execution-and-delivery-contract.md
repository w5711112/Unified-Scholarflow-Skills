# 执行与交付合同

每次交付前读取一次。本合同持有“三步，不多跑”、默认输出和六项交付门禁；规则命中、场景与文档表格格式由各自责任文件持有。

## 执行模型（三步，不多跑）

主循环开始前做一次准备：划受保护内容、判场景和目标读者、建术语表（首次出现的术语、缩写记录在案，供 R15 使用）。任务存在权威材料或多文档体系时，在同一次准备中记录来源优先级、各文档职责和承诺边界；不存在时不得虚构这套审计。整段没有可对应规则的改动时，直接说明并原样返回。原文干净就说干净，改写数量不是质量指标。

已有简体中文文件、段落或对话都可经过本合同。专业内容按 `专业语义草稿 → renhua → 格式 Skill` 执行：专业 Skill 负责事实、输入、处理过程和输出的完整性；renhua 负责语体、姿态、首次释义、主语、对象归属和自然表达；格式 Skill 只负责呈现。普通文字直接以原文、当前上下文和用户要求为基线。格式步骤新增实质性正文时，只把新增文字送回 renhua，不重跑未变化的全文。

1. **主循环**：按修补顺序把文本过一遍，命中即改，每处改动当场记编号。修补顺序为：结构 R17 → 语气与内容 R4/R5/R8/R13/R14 → 句式 R2/R3/R6/R9 → 标点与用词 R1/R7/R12 → 连贯 R10/R11/R15/R16。它只是主循环内的处理次序，不是每条规则各扫一遍全文。
2. **一轮通读**：只查两组结果，连贯（R10/R11/R15/R16 的残留问题、跨文档指向）和洁净（R13/R14 的 AI 残留与失衡姿态）。
3. **对账输出**：保真对账（受保护内容逐项找回，实词逐个指出处）后，按输出契约交付。

通读和对账发现的新问题同样记编号修复；禁止在此基础上再发起新一轮全文重扫。已通过的局部检查只在输入指纹未变时复用；变化时只刷新相关记录及下游。

## 输出契约

默认输出三部分，用户说“只要正文”时只给第一部分：

```text
【改写稿】完整正文

【改动说明】按编号列出：R几+改了哪里（一行一条，只列主要的）

【待确认】
- 已删除的整句姿态层（附原句）：不同意哪条就回退哪条
- 需补信息（无源引用、未定义术语、材料单薄处）：原文缺什么
```

输出约束：

- 整句纯姿态层的删除必须逐条列入「待确认」并可回退；短语级空洞修饰在「改动说明」中计数。
- 无源引用、未定义术语、原文疑似虚假因果、材料单薄处和作者占位符只列需补信息，不虚构答案。
- 改动说明只列主要改动，但 `EDIT_LEDGER` 内每处实际改动仍须对应 R 编号；对应不了的撤销并恢复原文。
- 原文没有命中项时说明原文已干净并原样返回，不为了制造改动而改写。

## 交付门禁（对账后逐项过，只引用规则不另立标准）

1. **保真**：铁律 1 的事实、职责、范围、承诺、限定和强调强度零漂移；铁律 3 的篇幅变化全部可归因。有权威材料时在这里一次核对来源覆盖和承诺边界，不拆到多个子部分重复验证。
2. **洁净**：R13 无 AI 服务话术、卑微讨好或无依据的攻击施压；R14 无历史指涉悬空、模型/编制过程残留和虚构引用物。正常礼貌、明确拒绝和有依据的强制条款不得被误删。
3. **连贯**：R10 代词先行词唯一；R15 术语先定义后使用、同物同名、上位能力没有无依据下放；R16 无指涉悬空、结论有新增信息、跨文档引用存在且版本一致。对承担主线的陌生词和复合词，还要确认动作主体、对象归属和输入输出关系足以让目标读者理解。
4. **呈现**：R1 破折号分号为 0、冒号引号在预算内；R11 句长无机械规律、无戛然而止。Word/WPS 或表格任务还须通过表格合同规定的属性与真实渲染检查。
5. **语域**：铁律 2 的用途、作者身份、目标读者和正式程度前后一致，整体不卑不亢。论文/工作文档不口语降格；对话、公众号和口播不被强改成学术腔。
6. **可审计**：每处改动对应现有 R 编号，对应不了的撤销恢复原文；多文档去重后的责任位置和交叉引用可定位。R2 命中处复用主循环记录，核对必要限定仍在、无关排除已处理，不另开防御性写作扫描。最终只形成一个综合判定。

## 最终判定

- 六项全通过才能判定完成；字数减少、AI 检测器评分或规则命中数不能替代门禁。
- 门禁发现的问题按原 R 编号做局部修复并更新相应下游，不启动第二轮全规则扫描。
- 无法在事实与强度守恒前提下修复时，保留保守版本并列入「待确认」，不得静默降格。
