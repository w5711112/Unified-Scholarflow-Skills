# Word/WPS 表格排版合同

仅当改写稿将写入 Word/WPS 等文档，或任务包含表格时读取。本合同只负责表格呈现，不得改变正文事实、术语、论证强度或用户明确格式要求。

## 交付表格排版约定

下列是用户未另行指定时的默认样式，适用于数模比赛论文、工作文档（实施方案、质量大纲、组织管理方案等）、基金本子等全部文档类型：

- **三线表默认**：仅保留顶线（粗，约1.5pt）、底线（粗，约1.5pt）和表头行下细线（约0.75pt），无竖线、无内部横线；不加载任何底纹、填充色、字体颜色强调。
- 全部单元格（表头与正文）水平居中、垂直居中；整张表在页面上水平居中。数字列需要小数对齐时用制表位或段落对齐属性实现，不用空格推齐。
- “居中”以读者在 Word/WPS 中看到的结果为准，不以代码已设置属性或 XML 中出现 `center` 单独代替。合并单元格要检查合并后的整体，含多个段落的单元格要逐段设置并逐段确认水平居中；所有单元格都要确认垂直居中。
- 单元格文字不得用固定空格（空格、全角空格或首行缩进）伪造缩进或对齐。段落缩进必须写显式零值直接格式（`w:ind firstLine=0`）；样式层用 `firstLineChars` 定义缩进时须同时写 `firstLineChars=0`，否则 Word 保存时会按样式回潮出“空两格”，仅删除直接格式无效。
- 对齐一律通过段落对齐属性设置，禁止在单元格文字前后添加空格调整位置。
- 相邻两张表格之间必须插入一个空段落分隔，否则 Word/WPS 会把两表合并为一张表。
- 单元格文字默认五号（10.5pt）宋体；中文字体不得用空格或其他字体替代（用户于 2026-08-31 补充确认的默认字号与字体）。

用户明确指定的模板、期刊或单位格式优先；只覆盖其未规定部分。格式处理后必须完成两类证据：先检查段落/单元格/表格属性，再用 Word、WPS 或等效真实渲染查看最终页面。至少覆盖普通单元格、合并单元格、多段落单元格以及保存后重新打开的结果，并确认没有空格推齐、样式缩进回潮、相邻表合并、底纹或多余边线。两类证据缺一时只能说明“属性已设置”或“尚待视觉确认”，不能声称表格已经真正居中并通过交付。
