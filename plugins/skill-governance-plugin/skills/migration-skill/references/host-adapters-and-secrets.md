# 宿主适配与秘密边界

只读取并执行当前目标宿主的分支；不得把某一宿主的私有工具名写成平台无关能力。

## Codex

保留标准 `skills/<name>/SKILL.md` 和相关资源。若是插件，使用目标 Codex 当前支持的 manifest、安装和缓存刷新流程；不要假设源机器的应用连接器、浏览器登录态或自动化状态会随目录复制。

## Claude Code

把平台无关 Skill 内容放入目标环境能发现的 skills 目录，使用 Claude Code 当前版本支持的插件或 Skill 清单。将网页、Shell 和文件操作映射到其真实工具；没有 PDF 或外部应用写入能力时按能力矩阵降级。

## Kimi Code

保留 Skill 主体与资源目录，使用 Kimi Code 当前支持的插件清单和重载方式。不要恢复过时的 Kimi-only 私有工具名，也不要把安装目录中的复制品当作自动更新的源目录。

## 普通 Agent

没有插件系统时，提供一个很短的入口指令，要求它完整读取目标 `SKILL.md` 及直接引用资源。若普通 Agent 不能读写 UTF-8 文件、运行必要脚本或访问任务所需证据源，就只能执行能力矩阵允许的子集。

## 配置与秘密边界

- 可迁移：示例配置、字段说明、相对路径合同、依赖版本、测试夹具。
- 目标机重建：绝对路径、调度时间、运行时安装、应用连接配置。
- 禁止复制：API key、token、cookie、浏览器登录态、OAuth 凭据、用户认证数据库和私有会话记录。
- 秘密缺失时，请求用户在目标宿主完成授权；不能把秘密写进 Skill、指南、日志或迁移包。

配置含源机器绝对路径时，生成目标侧显式配置或相对路径合同，不假定原路径可用。外部写入能力缺失时，只生成 dry-run 或可验证中间产物，不用浏览器或 Shell 冒充未具备的连接器，也不宣称端到端等价。
