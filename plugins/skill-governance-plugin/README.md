# Skill Governance Plugin

面向多 Skill 工作区的治理与发布插件，包含故障复用、跨环境迁移、生态注册、工作区整理和 GitHub 去隐私发布五项能力。

| Skill | 作用 |
|---|---|
| `collect-bug-update-accelerate` | 记录真实技术故障并复用已验证的解决路线。 |
| `github-upload` | 生成去隐私公开副本，补齐文档、审计并在确认后发布。 |
| `migration-skill` | 在不同 Agent 环境之间迁移并验证 Skill。 |
| `skill-ecosystem-governor` | 同步 Skill 注册、依赖、指南和锁定关系。 |
| `workspace-hygiene` | 以预演、隔离和可恢复方式检查工作区。 |

公开包不携带维护者本机的生态注册表、运行态锁或故障数据库。使用前请按自己的 Skill 根目录配置注册信息，并阅读各 Skill 的 `SKILL.md` 与 `REQUIREMENTS.md`。
