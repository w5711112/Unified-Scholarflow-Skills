## 用途与硬边界

概念桥的作用是调用读者已经学过的结构，帮助回忆和理解当前知识；它不能代替当前知识的定义、公式、例子、成立条件与边界。

- **用户主动提出并确认**或此前已经逐条批准的概念桥，可以在批准范围内写入 Vault。
- **Agent 自主提出**的概念桥只能先形成候选关联卡，**必须先经用户确认**；用户未确认时，不得把它写入笔记、图例、公式卡或 WikiLink，也不得换一种措辞暗中写入。
- 用户只批准了某一层联系，不自动批准范围扩张。例如批准“B-spline 重构具有低通特性”，不等于批准把任何平滑算法都称为低通滤波。
- 普通同领域计算例子、数值例子、反例和边界例子只是解释现有定义，不构成新的跨课程相似性主张，无需逐条审批。
- 候选桥等待确认时，继续完成不依赖它的当前领域定义、公式、例子和边界；只暂停候选桥本身。

## 可检索的已学范围

只有在确有助于解决当前疑问时，才从以下课程寻找候选结构，不为凑关联而罗列课程：

- C++ 程序设计、离散数学、数据结构、线性代数、计算机组成原理
- 信息论基础、概率论与数理统计、信号与系统、通信原理 C
- 自动控制理论（古典与现代）、智能机器人与无人系统、智能优化与控制技术（包括 fuzzy）
- 统计分析、数据库概论、计算机视觉与模式识别、机器学习、管理博弈论
- 基础范围可包括数学、物理、地理、生物；不提出化学类比

课程表只是检索边界，不是写作清单。没有通过结构门槛或没有获得用户批准的概念，不进入笔记。

## 候选概念桥的结构门槛

Agent 只有在两个概念共享至少一种可明确写出的机制时，才可提交候选：

- 相同或可对应的数学算子，如卷积、投影、差分、积分、优化或概率更新；
- 相同的状态转移、反馈回路、信息流、约束传播或因果结构；
- 能逐项对应输入、变换、中间量与输出，并能指出这种对应在哪里失效。

以下情况不能作为候选依据：

- 只因名称、外观、故事情节或一般功能相似；
- 只能说“都能平滑”“都能优化”“都与安全有关”，却写不出共同结构；
- 逐项映射含糊，或说不出具体区别与不能等同之处；
- 关联不能解决当前读者的一个明确疑问。

## 用户审核状态

| 状态 | 允许动作 | 禁止动作 |
|---|---|---|
| 用户在当前对话主动提出并确认 | 在明确范围内写入，并保留区别与边界 | 扩张成未讨论的普遍结论 |
| 此前已有逐条批准 | 按原批准范围复用 | 擅自增加新映射或新课程联系 |
| Agent 自主提出 | 只展示候选关联卡和确认问题 | 先写入 Vault、先建 WikiLink、把候选当事实落盘 |
| 用户未确认、暂缓或含糊回应 | 保留在对话候选态，正文继续 | 推定同意 |
| 用户拒绝 | 不写入；后续不反复推销同一桥 | 用近义表述绕过拒绝 |
| 仅做排版、错字或公式转义修正 | 不必重新确认语义未变的已批准内容 | 借编辑之机扩大语义 |

## 候选关联卡

Agent 自主发现候选时，用紧凑卡片向用户审核；每个候选单独确认，不捆绑审批：

```markdown
> [!question]- **候选概念桥｜待你确认**
> - **当前知识点**：……
> - **候选关联概念**：课程/基础学科中的……
> - **共同结构**：两者共同使用的算子、状态转移、反馈或因果结构是……
> - **逐项映射**：当前概念的 A/B/C 分别对应候选概念的 X/Y/Z。
> - **具体区别**：成立条件、对象、目的或不能推出的结论不同在哪里。
> - **拟解决疑问**：这条联系具体帮助理解哪一个问题。
> - **拟写位置**：直觉层/公式卡/读图与图例/边界段。
> - **确认问题**：你是否认为这条联系符合你的理解，并允许写入该位置？
```

确认问题不能只问“要不要加类比”；必须让用户看见共同结构、逐项映射、具体区别和拟解决疑问后再决定。

## 批准后的写法

已批准概念桥只写解决当前疑问所需的最短闭环，推荐顺序：

1. **共同结构**：先说两者为何能联系，明确共享算子或机制。
2. **逐项映射**：把当前公式中的量、步骤或状态对应到已学概念。
3. **解释收益**：指出它帮助理解的是形状、运算、因果链还是系统作用。
4. **具体区别**：说明对象、目标、条件、定义域或保证的不同。
5. **不能等同**：用一句话阻断最可能的过度推广。
6. **精确链接**：只有目标笔记真实存在且相关段落合格时才建立 WikiLink。

批准的概念桥仍是辅助层。正文必须先让读者仅凭当前领域解释理解定义和公式，再用概念桥完成回忆与串联。

## 已批准正例：B-spline 与信号处理

这条联系由用户主动提出并确认，可用于 B-spline 知识点；批准范围是**均匀/cardinal B-spline 的重复卷积、连续重构与频域低通特性**。

### 共同结构一：从矩形到平滑基函数

令单位间隔上的 0 次 cardinal B-spline 为

$$
\beta_0(\tau)=
\begin{cases}
1,&0\le \tau<1,\\
0,&\text{otherwise}.
\end{cases}
$$

它就是一个矩形核。更高次的 cardinal B-spline 可由重复卷积构造：

$$
\beta_k=\beta_{k-1}*\beta_0
=\underbrace{\beta_0*\beta_0*\cdots*\beta_0}_{k+1\ \text{个矩形核}}.
$$

因此形状可紧凑读成：

```text
k = 0          k = 1          k = 2          k = 3
 ┌───┐            /\            ╭──╮           ╭────╮
 │   │           /  \          ╱    ╲        ╱        ╲
─┘   └──       _/    \_      _╱      ╲_    _╱          ╲_
矩形区间开关      三角形         更平滑          更平滑
```

逐项映射是：矩形滑动时的重叠长度对应卷积值；一次重复卷积得到三角形；继续与矩形卷积，邻域信息被进一步融合，基函数阶数与平滑程度随之提高。

### 共同结构二：时域卷积对应频域相乘

采用 $\operatorname{sinc}(x)=\sin(x)/x$ 的约定，有

$$
\mathcal F\{\beta_0\}(\omega)
=e^{-j\omega/2}\operatorname{sinc}\!\left(\frac{\omega}{2}\right),
$$

$$
\mathcal F\{\beta_k\}(\omega)
=e^{-j\omega(k+1)/2}
\left[\operatorname{sinc}\!\left(\frac{\omega}{2}\right)\right]^{k+1}.
$$

相位项来自核的平移；观察幅值时，核心是 $|\operatorname{sinc}(\omega/2)|^{k+1}$。次数 $k$ 增大时，高频区幅值总体衰减更强，因此均匀 B-spline 重构呈现越来越明显的低通/平滑特性。轨迹尖角、快速摆动等高频变化因而被抑制，但不能据此宣称所有高频分量都消失。

### 共同结构三：离散控制点序列的连续重构

把控制点序列写成加权冲激列

$$
x(\tau)=\sum_i p_i\delta(\tau-i),
$$

再与 $\beta_k$ 卷积：

$$
p(\tau)=x(\tau)*\beta_k(\tau)
=\sum_i p_i\beta_k(\tau-i).
$$

这与 B-spline 曲线“控制点 × 平移基函数，再求和”是同一个计算结构。几何视角强调局部控制点的权重交接；信号处理视角强调离散序列经过重构核后变成连续平滑信号。两种视角相互印证，但关注点不同。

### 具体区别与适用边界

- **B-spline 首先是曲线空间的基函数和重构核**，不等同于一般意义下为某个系统单独设计的低通滤波器；这里的“低通”描述其重构核的频率响应特性。
- 简单的卷积与传递函数解释依赖均匀/cardinal、平移不变的基函数结构。非均匀 knot、重复 knot、夹持端点和有限区间边界会破坏这种最简移位卷积形式，必须回到 Cox–de Boor 定义分析。
- 次数升高通常使基函数更平滑，同时支撑区间也会变宽；“更平滑”不等于“局部影响范围更窄”。
- 轨迹平滑不自动保证无碰撞、动力学可行、最优或连续时间安全；这些仍需单独约束与验证。
- 频域解释说明平滑来源，几何凸包/局部支撑解释控制点怎样影响曲线；一个视角不能替代另一个视角的证明。

## 最终检查

- 这条联系是用户主动提出、此前批准，还是 Agent 自主提出？

- 已批准内容是否没有超出原审批范围？
