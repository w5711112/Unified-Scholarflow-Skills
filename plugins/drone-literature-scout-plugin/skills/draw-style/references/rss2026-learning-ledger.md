# RSS 2026 绘图学习总台账

本文件是 RSS 2026 参考图的单一汇总入口。它不替代逐图分析卡，而是长期保留两类内容：

1. **用户个人学习重点**：为什么选中这张图、最希望 `draw-style` 学会什么。该部分优先保真，不被后续概括稀释。
2. **补充核读**：在原尺寸逐元素、逐字符、逐连接检查后，补充用户未特别指出但可迁移的技巧、限制与反例。

执行顺序固定为：先登记用户重点 → 再看原图完整核读 → 写批次分析卡 → 用户校正/确认 → 才把稳定规则融合进场景参考。源图始终只读，不物理改名。

## 一、已确认的跨图读图原则

- 不能只评价“好看”。必须说明图表达什么、每个子图和对象的作用、所有可见箭头/连线的起止、图—图关系、文字—图形锚定关系，以及从中能吸收什么绘图方法。
- 字符、上下标、图例、坐标轴、单位和 caption 必须逐字符核对；看不清就写“未从截图确认”，不能凭领域常识补字。
- 每张图先归入范式：论文总图、知识点/局部原理示意图、论文数据图，必要时才使用混合类型。不同范式不能被压成同一种浅色框图风格。
- **知识点图**优先用最小但语义闭环的例子，让读者一眼理解区别、机制或空间关系；**论文总图**优先组织完整流程、模块关系和跨区阅读顺序；**论文数据图**优先保证数据映射、坐标、统计口径和比较条件准确。
- 立体感按语义选择 2D、2.5D 或 3D：只有高度、体积、包络、穿越、遮挡或空间相对关系确实承载信息时才增加维度。
- 高级感来自克制的近邻浅色、层级、对齐、适当轻阴影和稳定留白，不来自深色堆叠、夸张装饰或无意义立体化。
- **精确色号只在用户明确说颜色好看、值得学习或要求重点核对时采集。**若用户只评价结构或图型，则只分析颜色承担的分组、层级和数据语义，不把偶然出现的颜色并入偏好色板；RSS2026_031—040 的紫色尤其不作为高级紫参考。
