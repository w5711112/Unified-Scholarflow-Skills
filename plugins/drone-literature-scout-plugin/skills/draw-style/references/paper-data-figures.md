# 正式论文数据图/表格模式

## 1. 先确定统计语义

误差棒、阴影带和区间必须明确属于哪一种：

- **标准差（SD）**：样本离散程度；不能当作均值估计精度。
- **标准误（SE）**：均值估计的不确定性，通常随样本量变化。
- **95% CI**：置信区间；必须说明计算方法或 caption 中的正式定义。

截图或数据**未定义时不猜**误差棒含义，也不把三者互换。记录样本量、独立随机种子/任务/场景的统计单位；无法从证据确认时写“未确认”。

## 2. 数据合同

绘图前固定：数据来源、指标定义、方向（越高/越低越好）、单位、横纵轴、线性/对数尺度、聚合方式、点估计、误差定义、样本量、基线、显著性检验和缺失值处理。

- 数值精度服从测量/统计精度，不用过多小数制造虚假精确。
- 截断坐标轴、双轴、对数轴和归一化必须显式说明；不得夸大视觉差异。
- “Average”与具体条件用分隔线、间距或浅底色分区，但保持同一尺度。
- 排序应服务于研究问题：任务固定顺序、性能排序或类别结构需有明确理由。

配色和字体不在本文件复制一套色号表：默认从 `visual-language.md` 的六个核心色族、四条连续数据色阶和字体角色表选择。离散方法用核心色族加形状/线型备份，连续变量才从四条色阶中选一条。代码生成的坐标、刻度和数字首选 DejaVu Sans Regular/Semibold，Office/WPS 回退 Arial；终稿仍以 10–11 pt 实际可读性为准。

## 3. 图形与不确定性

- 分组柱状图适合少量离散条件和方法比较；柱顶误差棒线宽轻、端帽清楚，不遮挡柱体。若用装饰性 2.5D，只允许所有柱采用相同方向、相同距离的**固定偏移背板**，真实数值仍以前景柱顶为准；精确读数、密集柱或灰度打印优先时保持纯 2D。
- 折线图适合有序/连续自变量；点标记显示实际采样位置，**同色半透明不确定性带**只在 SD、SE、CI、分位区间或范围已被正式定义后使用。主线和节点比带区更饱和，类别型档位不做暗示连续函数的过度平滑。
- 同族且确有自然顺序的消融条件可用**单色相明度序列**：浅色起步、主方法最深，所有浅柱保留深色描边。无自然顺序的类别不能借渐变伪造顺序。
- 同一方法的少量嵌套配置可在同一 x 位置使用**嵌套高度层**并逐层标数值；图例必须声明它不是求和堆叠，缺少柱内数值时改用普通并列柱或折线。
- 多次轨迹或扰动样本采用**深粗中心趋势＋浅细个体样本**：中心趋势优先读取，个体线保留分布、异常和传播范围；浅线不是 SD、SE 或 CI，统计定义必须由图例或 caption 明示。
- 轨迹比较固定共享地图、尺度、障碍与扰动条件；起点、终点、控制点使用不同形状并辅以颜色。需要时按“共同场景 → 量化指标 → 方法 A 空间后果 → 方法 B 空间后果”组织证据链。
- 箱线图/**小提琴图**展示分布；小提琴宽度表示核密度，必须说明中心横线/点、带宽、样本量和显著性字母的检验与多重比较校正。少样本时叠加原始点或改用 raincloud/box plot，不能用平滑轮廓制造精度。
- 散点图说明相关/权衡时保留样本结构，必要时给趋势与区间但不遮蔽原始点。
- 表格适合精确查值；最佳/次佳强调不能替代显著性说明。
- 只突出最关键的基线—本方法差异时，使用锚定双方柱顶的**柱顶比较括号**并写明提升口径；不要为所有成对组合堆括号，也不能用悬空百分比。
- 多方法、多变体曲线采用**颜色编码方法、线型编码变体**，必要时再用线宽区分主基线；同一视觉通道不重复编码两个变量。
- 多环境×多参数×多轮次采用共享轴域、共享色条的 **small-multiple 热图**，行列标题承担条件索引；可配散点权衡、收敛曲线或逐轮热图补充不同证据，不能让多面板重复同一结论。
- 横向离散比较优先使用**圆角条形＋高占空比**：条体要厚、相邻条间距要紧，整体满足**条宽大于组间留白**；若还存在更高一级的语义大组，则在大组之间另设明显更宽的分隔空带。圆角只改善条端触感，不能改变数值终点；可用 `FancyBboxPatch` 生成圆角条，再单独叠加有端帽且统计含义已定义的区间。
- 折线端点可使用**白色外圈端点**，以深色实心中心保留方法身份、白色细边从阴影带或网格中分离采样位置；外圈是可读性装饰，不新增数据语义。
- 当柱高并非核心、又要保留基线到观测值的定位关系时，可用**菱形 lollipop** 替代柱状图：细虚线/细实线承担位置引导，菱形承担数值端点，颜色、空心/实心或外环可编码类别与名次。对数轴下 stem 应连接到当前可见下界或正式基准，不能假装从数值零出发。
- 权衡散点允许使用**图标化散点**：方法若有稳定的设备、模型或策略符号，可用小型矢量图标、星形、圆角方形等替代全圆点；图标必须再由直接标签、位置或颜色冗余编码，缩小或灰度打印后仍能识别，不能只靠 emoji 字体。
- 数据图默认采用**大号坐标文字**。在最终嵌入尺寸下，轴标题、刻度、图例和直接数值优先达到 10—11 pt；数字使用字腔饱满、`0/6/8/9` 易区分的无衬线体，不能用放大画布掩盖缩入论文后的细小文字。
- **包络带 small multiples**适合多任务、多状态下比较中心轨迹与上下界/可达集合：每格保留深中心线和同族半透明包络，行列标题固定任务与指标，跨格重复的图例移到公共位置。带区只有在 caption 明确后才能称 SD/SE/CI；若它只是上下界、可达域或样本范围，就按原语义命名。RSS2026_095 只提供这种结构，不作为默认 Matplotlib 配色模板。
- **组内倍率/差值 callout**用于读者真正关心“同组两柱相差多少”时：以灰色虚线箭头或括号精确锚定两根柱的顶点/中心，标签写 `2.9× decrease`、绝对差或相对变化，并在 caption 说明分母和方向。callout 不能替代原始数值和误差棒；误差棒竖线、中心点与端帽在终稿尺寸都要可见，不能像 RSS2026_099 那样细到接近抗锯齿线。
- **t-SNE 嵌入投影**用于把高维表示投到二维，定性检查训练/未见条件的邻域、重叠和分离。普通半透明圆点承担训练样本，少量未见对象可用带深色描边的五角星；星形是身份强调，不代表数值更大。t-SNE 轴没有物理单位，不能从二维全局距离、簇面积或密度直接推出原空间结论；需记录 seed、perplexity、预处理，并用定量指标补证。

## 4. 精华母版的数据实施合同

- **M4 不确定性合同**：深主线只表示已定义的中心趋势；浅带或端帽必须明确为 SD、SE、CI、分位区间或范围，浅个体线则明确为原始轨迹/扰动样本。误差端帽、中心点和 inset 在终稿尺寸仍须可辨。
- **M5 离散比较合同**：颜色编码方法，线型/形状编码变体；只有存在真实有序变量时才用同色相明度序列。直接标注、形状冗余和清楚端帽优先于装饰渐变。
- **M6 分布诊断合同**：violin/box/raincloud/scatter/radar 按研究问题选择；密度宽度、原始点、median/mean/CI、样本量和显著性必须分别定义，不能让一个白点或横线同时承担多个未说明统计量。雷达图先统一指标方向与归一化口径，再以半透明填充、顶点直接数值和形状/线型备份方法身份；图标化散点只在图标能作为方法身份且有文字冗余时使用。
- **M7 响应面合同**：区分离散散点、栅格 pseudocolor heatmap、filled contour 与 3D surface。二维位置承载两个变量、颜色承载连续标量时，必须给 x/y 名称与单位、数值色条、方向和插值/拟合边界；平滑色面不证明原始采样密集。采用**测量点＋插值曲面**时，**黑色实测点**是证据，曲面只是拟合/插值；可用**白色曲面网格**显示单元结构，但不得把网格交点冒充额外观测。比较正则化强度或策略支持变化时，可用共享坐标域的**有序密度支持序列**，让 filled contour/KDE 从宽支撑、分裂到收缩逐面板演化，并固定 levels、带宽与归一化口径。
- **覆盖场＋阈值边界**用于回答“某个候选位置能使哪些空间区域满足方差、可见性、风险或覆盖阈值”。底层 pseudocolor/heatmap 编码连续场，候选位置用高对比 `×`、星形或圆点，阈值集合用单条虚线/实线 contour 圈定；多候选面板必须共享轴域、`aspect`、归一化和**共享色条**。色条标题写清 covariance/variance/probability 等量名；候选位置与覆盖边界是叠加证据，不是热力像素的一部分。
- **安全集场＋零水平边界＋梯度箭头**用于 bounded Q、可行值函数或 barrier 场：连续色面编码标量，`Q=0` 等值线分隔安全/非安全集合，局部梯度箭头必须由场导数计算并只在需要的位置采样，星形标示专家/目标状态。前视、侧视、俯视等投影必须共享轴域、归一化和**共享色条**；箭头不是装饰，黄色星也不能脱离图例。RSS2026_101 的结构可学，字体偏小和普通色图不照搬。
- **协方差椭圆**只有在由真实协方差得到时才使用：中心、旋转方向、长短轴分别对应均值、特征向量与扩散尺度；未定义概率质量时不称 95% confidence ellipse。
- 能量/密度图中的**等值线不是物理水波纹**：闭环表示等值集合，间距反映局部变化快慢；叠加粒子、模式中心或优化点时，位置和形状必须来自同一坐标系。

### 4.1 证据分层而不花哨

数据图的丰满感应来自原始证据、统计解释与事件语义，而不是无定义底色或图标堆叠。按研究问题选择以下层，并在图例或 caption 中逐层定义；不是每张图都要全部叠加。

- **实物场景—定量诊断映射**：照片中的真实对象、姿态或场景条件与数据点/时间窗存在一一对应时，可用 `场景照片 ↔ 可靠性/时间数据 ↔ 事件点` 组成混合证据。实线或虚线连接只表达“对应”，不冒充因果；连接端必须落到具体对象和具体数据点，不能只指向整个面板。
- 可靠性图中的红色对角参考线、中心趋势和两层**分位区间**各有独立职责。分位区间不是 SD、SE 或 CI；时间曲线下方的面积填充也可能只编码量值积累，不能一见浅带就称“不确定性”。事件窗、阈值线和碰撞标记必须来自同一时间轴。
- **雷达灰色坐标骨架**采用低对比同心圆环和径向支撑线；它们只辅助比较，不承担方法身份。顶点标记要在终稿尺寸可见，方法较多时用线型、直接标签或轻透明填充冗余；先统一指标方向、归一化和轴顺序。
- **共享坐标域的算法轨迹比较**适合优化、约束满足、模式切换和策略更新：所有面板固定目标等值线、可行域、轴域与尺度，只改变方法路径、迭代节点、松弛变量或更新规则。粗轨迹、编号节点、极限点、局部公式和事件 callout 都必须有算法定义；丰富来自证据层，不来自装饰层。
- 两条共享横轴且有效支持一致的系列可以增加**差值解释层**，直接显示 gap 随条件变化。填充区域必须由两系列真实差值构成；若某系列缺少一段 x 支持，差值层只能从共同区间开始。避免用巨大低对比文字占据数据区，也不能让差值面积替代原始曲线。

判断一层是否保留时，必须回答：`它编码什么数据，帮助读者判断什么？` 无法回答就删除。图型候选和软件路线先按 `data-chart-selector.md` 决定，本文件只负责选定图型后的统计与视觉实施。

## 5. 3D 空间数据图

正式论文数据图不限于柱状图和折线图。数据是三维采样、集合边界、位姿不确定性或空间占据时，可选择真正的 **3D 空间数据图**：

- 离散分布用**内部散点**；集合范围用带实线棱边的**半透明多面体**；复合局部占据或不确定性并集可用**半透明球体**或椭球体。点、面、体必须对应真实数据类型，不能把示意装饰当数据。
- **三轴名称与单位**必须逐轴写全；刻度方向、步长和小数精度匹配真实范围。说明轴是否按真实比例、归一化或人为拉伸，比较图固定 `box aspect`、轴域和投影视角。
- **相机角度**必须同时露出三个轴和关键包含/重叠关系；透明面用棱线、轮廓、切片或投影补偿遮挡。网格线保持很浅，图例不能覆盖高密度数据区。
- 3D 包络负责直觉，覆盖率、体积、样本量或误差仍应由 caption、正文或配套统计图给出；不能只凭透视大小宣称方法更优。
- 时间演化的 3D surface small multiples 只在“曲面拓扑、峰/谷或零平面穿越”本身是结论时使用；固定 `view`、轴域、z 范围、色彩归一化和参考平面，并优先使用单一共享色条。若结论只是安全域扩张或高低区域变化，2D contour/heatmap 通常比 RSS2026_102 式四个默认 3D pane 更准确紧凑。

### 5.1 信息地形—轨迹—局部方向组合

当论文要同时回答“信息/代价地形在哪里高”和“机器人怎样沿地形行动”时，可采用上部 3D 地形、下部局部方向示意的组合，而不是把下图误称为上图的二维投影：

- 上部以 `numpy.meshgrid` 建坐标域，用 Matplotlib 的 `plot_surface` 绘制淡色曲面、`plot_wireframe` 叠加稀疏网格，再以 `plot3D` 绘制连续黑色轨迹、`scatter` 标出起点/阶段点/终点；比较方法时固定 `view_init`、轴域、box aspect、网格密度与光照。
- 下部的状态、速度或梯度方向用 `FancyArrowPatch` 绘制有控制点的柔和箭头；需要白色外轮廓时使用 `matplotlib.patheffects` 的 `path_effects.withStroke`，而不是复制一根错位白箭头。
- 3D 表面负责全局标量场，黑色路径负责行为，彩色阶段点负责时间锚点，下部方向图负责局部机制；四类视觉对象职责不能互换。若原论文未公布源码，这只是 Python/Matlab 的等效复现语法，不据此断言作者使用了哪一种软件。

### 5.2 实测点—插值曲面复现骨架

RSS2026_062 的有效结构不是普通“彩色 3D 方格”，而是把原始证据与连续解释分层：黑点给出真正评估过的参数组合，红—近白—蓝曲面给出这些点之间的插值，白色网格只帮助读者看清曲面单元。

- **Python/Matplotlib**：把类别轴编码为固定整数，用 `meshgrid` 建表面坐标；先以公开的插值器生成 `Z_fit`，再用 `plot_surface(X, Y, Z_fit, cmap=..., edgecolor='white', linewidth=0.8, antialiased=True)`，最后用 `scatter(x_obs, y_obs, z_obs, c='black', s=55, depthshade=False)` 叠真实点。自定义色图可用 `LinearSegmentedColormap.from_list` 建 `#568BBF → #F9F8F6 → #B94E5E`。
- **MATLAB**：用 `surf(X,Y,Zfit,'EdgeColor','w','LineWidth',0.8)` 绘面，`hold on; scatter3(xObs,yObs,zObs,60,'k','filled')` 叠点；若原始点不在规则网格，先明确采用 `scatteredInterpolant`、`griddata` 或其他方法，并在 caption 写出外推边界。
- 两个面板比较时固定 `view`/`view_init`、轴域、box aspect、色条方向和类别轴顺序。若两图数值范围不同，可以分别给色条，但不能用相同红色制造“值相等”的错觉；若共享色条，则必须共享规范化范围。
- 红白蓝两端色容易被读成“相对某个中点的正负偏离”。只有中点有正式基准时才称 diverging；若只是低到高的性能，可保留这种视觉复现，但 caption 和色条必须明确低/高含义，通用新图优先考虑感知单调的顺序色图。

## 6. 视觉严谨

轴标题含单位，网格线浅且只辅助读数；图例顺序与柱/线出现顺序一致。有限样本置信区间（包括 `95% finite-sample CI`）在 caption 写清构造口径，线和端帽在最终印刷尺寸必须可见；CI 重叠不能直接替代显著性检验。颜色要通过灰度打印和色盲可辨检查，并辅以线型、标记或纹理。Caption 应自包含：说清数据集/任务、方法、点估计、误差定义、样本量、统计单位与主要结论。

### 6.1 绘图区占用与终稿字号

- 数据主体在**有效绘图区**内的目标占用率通常为 **70%—85%**。轴域、面板比例和图例位置应让主要条形、区间、点云、热力矩阵或曲线占据视觉主体，禁止把数据缩在角落后留下大面积**无意义留白**。
- 横向或纵向条形应优先做到条宽大于同级组间留白。分面之间只保留足以区分语义的空隙，不用均匀大间隔稀释信息密度。
- 在论文实际嵌入宽度下，轴标题、刻度、图例、直接标注和面板字母优先使用 **10—11 pt**，关键数字适度加粗。需要缩小字号才能塞下时，先重排、合并标签或改变图形，而不是让整张图变成细小文字包围的白底。
