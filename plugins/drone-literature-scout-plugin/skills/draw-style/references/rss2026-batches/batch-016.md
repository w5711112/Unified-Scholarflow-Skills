## RSS2026_076
<!-- rss2026-meta {"visible_figure_label":"Fig. 2","figure_track":"method/schematic","domain_tags":["FreeOcc","Point Cloud","3D Gaussian Map","Occupancy Mapping"]} -->

### 1. 截图身份

- 原文件：屏幕截图 2026-08-02 012643.png。
- 定位信息：`Fig. 2: Framework Overview of FreeOcc.`。
- 图的范式类别：四层地图构建与开放词汇查询的高密度系统总图。
- **用户个人学习重点**：整体偏花哨；实物图太多但逻辑不够突出，渐变色粗箭头不合场合，应谨慎参考。
- **补充核读**：图中确有 Layer 1→2→3→4→Query 的完整蛇形主链；问题不是完全无逻辑，而是照片条、虚线框、渲染图、渐变箭头和对话框同时抢占注意力，使主链低于素材密度。

### 2. 图本身表达什么

FreeOcc 从 RGB(-D) 序列和 SLAM 点云构建几何一致的 3D Gaussian map，再通过开放词汇语义关联形成 semantic Gaussian map，投影为 occupancy map，最后支持在线开放词汇占据查询和语义定位。

### 3. 逐元素与连接核读

**逐元素账本：**

- Layer 1 绿色虚线圆角域：顶部 RGB(-D) 视频条和深度/伪彩条；右侧 `DROID-SLAM Backbone`；下方相机位姿与点云框、点云渲染和视锥示意。
- Layer 2 蓝色虚线圆角域：左侧彩色 SLAM 点云，中部含多个椭圆 Gaussian primitive 的立方体，右侧 3D Gaussian 场景渲染；底部标题强调 geometrically consistent update。
- Layer 3 紫色虚线圆角域：上方原始视频条与语义着色视频条；下方 RGB primitive、VLM model 神经网络符号和 Semantic primitive 立方体。
- Layer 4 橙色虚线圆角域：Gaussian primitive 立方体经箭头变为彩色 voxel occupancy 场景。
- 右下红色虚线圆角域：顶部 benchmark 图像条和机器人提问 `Where is “Lamp”?`；下方在线点云/占据结果、机器人回答和突出灯区域。

**箭头/连线账本：**

- RGB(-D) sequences → DROID-SLAM｜黑色直箭头｜无边标签｜输入序列进入 SLAM。
- DROID-SLAM → camera poses & point clouds｜黑色向下箭头｜无边标签｜输出位姿与点云。
- Layer 1 → Layer 2｜绿蓝渐变粗向下箭头｜无边标签｜从稀疏/半稠密点云进入 3D Gaussian map。
- Layer 2 → Layer 3｜蓝紫渐变粗向上箭头｜无边标签｜几何 Gaussian map 进入语义关联。
- Layer 3 → Layer 4｜紫橙渐变粗向右箭头｜无边标签｜语义 Gaussian 投影到 occupancy。
- Layer 4 → Query 区｜橙红渐变粗向下箭头｜无边标签｜占据表示支持在线查询。
- 点云 → Gaussian cube → 3D scene｜黑色两段直箭头｜无边标签｜Layer 2 内部构建过程。
- RGB primitive → VLM → semantic primitive｜黑色直箭头｜VLM Model｜Layer 3 的语义嵌入过程。

**关系账本：**

- 图—图关系：五个大域是阶段链，多个视频条、立方体和渲染图是同一表示在不同阶段的实例。
- 文字—图形关系：Layer 标题给阶段身份，底部大标题给局部运算，caption 展开每层正式职责；机器人气泡只说明最终查询例子。

### 4. 全局构图与阅读路径

左侧 Layer 1 在上、Layer 2 在下，中间 Layer 3 在上，右侧 Layer 4 在上、Query 在下，形成上下折返的蛇形路径。大域占用充分，但每域内部又包含多种介质，阅读者需要不断寻找下一支箭头。

### 5. 局部视觉语法

各层使用不同浅底、深色虚线圆角边和同色标题；跨层用双色渐变粗箭头。视频条带有胶片孔装饰，Gaussian 用半透明椭圆体，occupancy 用 voxel，查询用机器人线稿与气泡。字体在衬线、粗体彩色标题和对话文字之间切换。

### 6. 为什么部分有效、部分失效

表示转换本身有较完整的实例链，读者能看到点云、Gaussian、semantic、occupancy 的形态变化；但重复素材和多套装饰让每层的关键创新与普通输入同权，跨层箭头的渐变又增加了不必要的视觉重量。

### 7. 可以吸收的绘图知识

- 只吸收“不同表示各保留一个代表实例”的跨表示身份思路，不吸收素材数量。
- 四层系统先画单色主链，再为每层选择一个输入、一个关键变换、一个输出；详细视频条移到局部 inset 或补充材料。
- 渐变箭头只有在箭头本身编码连续量时使用；阶段流转用单色职责箭头更准确。
- 该图可由矢量排版组合现有渲染输出，但必须先统一照片裁切、边框、白平衡和字体。

### 8. 不足、误读风险与不应照搬

照片条重复、标题过多、虚线彩框和渐变粗箭头同时出现；VLM、机器人和 Gaussian 的绘制风格不统一。部分箭头跨越较大空隙，主链需要依靠 Layer 编号才能恢复。不能把“内容多”当成总图完整，也不能用渐变箭头弥补阶段关系不清。

### 9. 本图最值得学习什么（收录理由）

主要作为反例：系统确有完整逻辑，但视觉层太多导致主次丢失。其价值是帮助 draw-style 明确删减顺序——先冻结主链和表示转换，再删除不承担独立证据的重复照片与装饰。

### 10. 证据边界

每个缩略图是否来自同一序列、Gaussian primitive 的真实参数、箭头渐变是否有正式语义、查询结果生成过程、素材来源和绘图软件未从截图完整确认。

### 1. 截图身份

- **用户个人学习重点**：整体一般，没有特别突出的风格。
- **补充核读**：有限可吸收点是把两方法之间的差值直接填成 `Error Gap`，并在低数据区域用两个蓝色面积与括号解释误差下降构成；但其图例、巨型文字和有效横坐标范围存在风险。

### 2. 图本身表达什么

随着训练轨迹从 1 增加到 5，不使用预训练的定位 RMSE 逐步下降，但仍明显高于使用预训练的模型；预训练模型从 0 到 5 条轨迹保持较低误差。图中另外把 one-shot/five-shot 微调误差下降划分成两个比例部分。

### 3. 逐元素与连接核读

**逐元素账本：**

- 横轴为 `Number of Training Trajectories`，刻度 0—5；纵轴为 `Position RMSE (m)`，范围约 0.25—2.00。
- 蓝色实线圆点为 `With Pretraining`，从 x=0 到 5；紫红虚线方点为 `Without Pretraining`，从 x=1 到 5。
- x=1—5 的两条曲线之间填浅紫区域，中央写大号低对比 `Error Gap`；x=1 附近有 `error × 5.5` 小框和左指箭头。
- x=0—1 的蓝色曲线下/曲线间有深浅两个蓝色三角面积，图例分别标 `Finetune Err Drop (Oneshot)` 与 `Finetune Err Drop (FiveShot)`；左侧蓝括号和文字标 71.56%、28.44%。
- 右上图例为白底浅灰边框，覆盖靠近上方曲线的区域。

**箭头/连线账本：**

- `error × 5.5` 框 → x=1 的紫色差值边界｜短灰色左箭头｜error × 5.5｜强调两方法误差比例。
- 深浅蓝面积 ↔ 左侧括号百分比｜蓝色括号，无方向｜71.56% / 28.44%｜把总下降拆成两部分。
- 两条折线内部只连接同方法相邻训练轨迹，不表示跨方法因果。

**关系账本：**

- 图—图关系：单坐标图内同时有主比较、差值解释和低样本比例分解三个层次。
- 文字—图形关系：图例定义线与面积，`Error Gap` 直接命名紫色差值层，caption 说明预训练/非预训练与训练轨迹数量。

### 4. 全局构图与阅读路径

主图横向展开，蓝线靠近底部，紫线和浅紫差值占据上半大区。大面积填充令差距成为视觉中心；左下括号形成次级入口。右上图例较大，和高值曲线相邻。

### 5. 局部视觉语法

方法同时用颜色、线型和标记冗余；差值区用低饱和浅紫，局部下降用深浅蓝。轴标题和刻度较大。`Error Gap` 采用超大衬线文字且透明度低，与坐标数字字体不一致。

### 6. 为什么有限有效

差值面积把“预训练好多少”从两条独立曲线变成直接可见的比较层，线型与标记在灰度中仍有区别。但大字和大面积填充可能让视觉差异强于精确数值，且 x=0 时紫色系列缺失。

### 7. 可以吸收的绘图知识

- 有限吸收“差值解释层”：只在两系列共享横轴支持且差值本身是结论时填充。
- 比例分解可以用相邻面积＋括号直接标注，但分母和计算口径必须写在 caption。
- WPS 可完成简单折线和面积；支持范围处理、复杂括号和文字避让更适合 Python。

### 8. 不足、误读风险与不应照搬

`Error Gap` 文字过大，图例覆盖数据邻域，浅紫面积可能夸大视觉差；Without Pretraining 没有 x=0 观测，不能把差值延伸到零。括号百分比的计算基准无法从图中独立恢复。不要照搬超大透明文字和满区填色。

### 9. 本图最值得学习什么（收录理由）

只保留“共享横轴的差值解释层”和局部比例括号两个技巧，并把公平支持范围和文字尺度写成反向约束；不升格其整体配色或排版。

### 10. 证据边界

误差是否为均值、是否含不确定性、样本量、`error × 5.5` 和两个百分比的计算公式、x=0 非预训练数据是否缺失、绘图软件未从截图确认。

### 1. 截图身份

- 原文件：屏幕截图 2026-08-02 012813.png。
- 定位信息：`Fig. 3: The framework of our proposed AnyAmber ...`。
- 图的范式类别：多机器人测距、匹配、图优化和去中心化通信框架图。
- **用户个人学习重点**：右上留白明显、不够紧凑；无人机/机器人绘制不形象；同级色块差距过大。

### 2. 图本身表达什么

UWB range sequence 经传感器嵌入的 GRU 滤波，向 coarse/refined PGO 提供不确定性与滤波距离；多帧匹配网络从多机器人任务中输出 prior bearing，EGAT 融合 prior pose 与 bearing，Robot-A 再与 B/C/D 通过广播通信进行去中心化优化，最终输出优化位姿。

### 3. 逐元素与连接核读

**逐元素账本：**

- 左上 UWB 天线和紫色无人机图标构成 `UWB Range Seq` 输入；顶部中央绿色虚线圆角框为 `Sensor-embedded GRU Range Filter`。
- 左中黄色框为 `Coarse PGO`，中央紫色框为 `Unified Heterogeneous EGAT`，右中橙色框为 `Refined PGO`。
- 左下灰色虚线大框为 `Multi-Robot Task`：含移动机器人剪影、无人机位置图、透视视锥和蓝色目标无人机；内部蓝色框为 `Multi-frame Matching Network`。
- 中右灰色点虚线小框为 `Robot-A`，含机器人姿态和三架无人机；其下有 Broadcast 图标。
- 右下黑色虚线大框为 `Communication for Decentralized Opt`，内部三格分别是 Robot-B、Robot-C、Robot-D。
- 最右侧数学斜体 `Opt Pose` 为输出。

**箭头/连线账本：**

- UWB Range Seq → GRU filter｜黑色直箭头｜无边标签｜测距序列输入。
- GRU filter → Coarse PGO / EGAT / Refined PGO｜顶部黑色长括号式分叉箭头｜Uncertainty / Filtered Range｜滤波输出分送不同模块。
- Coarse PGO → EGAT｜黑色直箭头｜Prior Pose｜粗位姿先验。
- Multi-Robot Task → Matching Network｜黑色直箭头｜Prior Bearing｜多帧匹配输入。
- Matching Network → EGAT｜黑色向上弯箭头｜Matched Bearing｜方位匹配结果。
- EGAT → Robot-A｜黑色直箭头｜无边标签｜融合表示进入主机器人状态。
- Robot-A → Refined PGO｜黑色直箭头｜Pose / Cov｜位姿与协方差进入精化。
- Robot-A ↔ B/C/D 通信域｜黑色虚线向下与向上连接｜Broadcast / Pose & Cov｜去中心化信息交换。
- Refined PGO → Opt Pose｜黑色直箭头｜无边标签｜输出优化位姿。

**关系账本：**

- 图—图关系：上部测距链、左下匹配链和右下通信链在 EGAT/Robot-A/Refined PGO 处汇合。
- 文字—图形关系：边标签承担 uncertainty、range、pose、bearing、covariance 的数据身份；色块标题给算法模块，机器人图标给主体身份。

### 4. 全局构图与阅读路径

主体分布在左上、中央和下方，右上 Refined PGO 上方留下大面积空白。顶部超长分叉线跨越整个宽度，底部大容器又形成第二视觉重心；主流程需要在上下之间多次跳转。

### 5. 局部视觉语法

绿色、黄色、紫色、蓝色和橙色浅填充配同色虚线边框；外层容器又使用灰/黑虚线。图标混合扁平无人机、移动机器人剪影、广播符号和数学文字；粗体无衬线、普通衬线、斜体输出并存。

### 7. 可以吸收的绘图知识

- 仅保留“多路输入在真实融合前保持分离”和 edge label 直接标数据身份。
- 重绘时应把 Robot-A 或 EGAT 设为单一视觉锚，将 filter、matching、communication 作为三个卫星域；Refined PGO 紧贴输出，避免右上空洞。
- 同级模块颜色应从同一浅色体系选择，深边/箭头承担身份，不用高差异色块平均轮换。

### 8. 不足、误读风险与不应照搬

右上空洞、顶部括号线过长、同级色块差异强、无人机与机器人素材风格混杂、虚线边框类型过多。部分箭头靠近文字或需要跨区回读。不能把所有模块都画成不同颜色，也不能用大弧线填补没有组织好的空间。

### 9. 本图最值得学习什么（收录理由）

作为“技术关系基本齐全但视觉层级不足”的反例，用于强化非对称布局仍需视觉锚、对齐线、统一图标和克制色彩，而不是任意错位。

### 10. 证据边界

各模块训练/推理边界、EGAT 的输入输出张量、通信方向与频率、协方差用途、图标所代表的平台和绘图软件未从截图完整确认。
