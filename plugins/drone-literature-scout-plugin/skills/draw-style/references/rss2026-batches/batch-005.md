### 1. 截图身份

- 原文件：屏幕截图 2026-08-02 001151.png。
- 定位信息：标题以 Fig. 10: Kinematic sequence of the eel robot 开头。
- 图的范式类别：知识点/局部原理示意图（时间序列运动学快照）。
- **用户个人学习重点**：学习其特别简洁但形象地表达核心意思；用横向 0 s、1 s、2 s、3 s 和合适的横向大括号精准写出各阶段；与前面同类极简图综合，合并同类项，提炼共同规律。
- **补充核读**：本图的简洁不是删掉语义，而是把“对象状态、时间、阶段、参数、运动方向”全部直接锚定在同一根时间轴上。

### 2. 图本身表达什么

鳗形机器人从 0–1 s 的 Bending Phase 将直体卷曲成 C 形，并以五个关节弯曲角 θ₁:₅ 参数化；1–3 s 的 Propulsion Phase 使身体伸直并向尾部传播行波，以相位 φ 和波长 λ 参数化，从而朝紫色箭头方向快速转向。

### 3. 逐元素与连接核读

- 0 s：绿色直体竖直放置，五个紫色关节圆点沿身体等距排列。
- 1 s：同一对象卷成 C 形；橙色虚线从局部关节切向/骨架延伸，橙色弧线与 θ₁:₅ Bend Angles 就地解释弯曲参数。
- 2 s：身体开始伸直并转向；紫色箭头指向新的运动方向。
- 3 s：身体成为横向行波；橙色横向双端标尺标 λ Wavelength，尾部附近以橙色弧线标 φ Phase，紫色箭头继续指示方向。
- 下方黑色时间轴从 0 指向 t，0 s 为黑点，1、2、3 s 为竖刻度。
- 时间轴下第一条横向大括号覆盖 0–1 s，标 Bending Phase；第二条覆盖 1–3 s，标 Propulsion Phase。

**箭头/连线账本：**

- 0 s 快照 → 1 s 快照｜黑色实箭头｜无边标签｜状态推进。
- 1 s 快照 → 2 s 快照｜黑色实箭头｜无边标签｜状态推进。
- 2 s 快照 → 3 s 快照｜黑色实箭头｜无边标签｜状态推进。
- 2 s 与 3 s 的紫色箭头｜紫色实箭头｜caption 定义为新 heading direction。
- 橙色角度虚线与弧线没有流程箭头含义，只是参数几何辅助线。

**关系账本：**

- 四幅快照保持同一个机器人、相同关节数量、相同颜色身份，只改变姿态与朝向。
- 时间刻度与大括号共同承担“瞬时状态”和“阶段区间”两层时间语义。
- 参数文字直接贴近对应几何，不另设图例或公式卡。

### 4. 全局构图与阅读路径

横向四快照与时间轴形成单一阅读脊柱。主体上方只有必要参数，下方只保留阶段括号；没有容器框、底色或冗余装饰。0–3 s 的比例通过刻度与括号直接可见。

### 5. 局部视觉语法

- 机器人身体绿 #00BA57；关节与方向箭头紫 #B167DA；参数与构造线橙 #F0AC17。
- 对象轮廓较粗，关节圆点有黑色细边；阶段文字与时间轴为黑色。
- 三种颜色分别固定“身体”“关节/运动方向”“待优化运动学参数”，没有交叉复用。

### 6. 为什么有效

读者无需读 caption 就能复述“直体→弯曲→伸直→传播行波”，还能知道何时切换阶段、每阶段由哪些参数控制。阶段括号比再套两个大容器更节省空间，也更精确地锚定时间区间。

### 7. 可以吸收的绘图知识

- **新增候选：极简状态序列共同规律。** 固定同一对象、尺度、颜色与阅读方向，只改变要解释的状态变量；用一根共享的时间/条件轴承载顺序。
- **阶段分组优先使用区间括号。** 当分组本质是连续时间区间时，括号端点直接对齐刻度，比圆角框更精确、更轻。
- **参数就地锚定。** 角度、相位、波长贴近对应曲线或关节；颜色将参数文字与构造线绑定。
- 与 RSS2026_010 的“同构场景只改变条件/结果”、RSS2026_019 的“每项主张选择最短证据”合并后，可形成：共享对象与基线 → 只改变一个核心状态 → 就地标差异 → 用最轻量的顺序/结果符号收束。

### 8. 不足、误读风险与不应照搬

部分橙色文字在白底上的对比度偏低；小尺寸下 θ₁:₅、φ、λ 可能变细；黑色状态推进箭头没有时间标签，必须依赖下方时间轴；不适合并行分支很多或状态对象会增删的复杂系统。

### 9. 本图最值得学习什么（收录理由）

学习“同一对象四快照＋一条时间轴＋两个区间括号＋就地参数”的极简闭环，并把它与已有极简示意合并为通用的状态变化表达规律。

### 10. 证据边界

关节真实角度数值、相位与波长的数值、流体力方向、快照是否按严格时间比例绘制，以及紫色箭头的定量速度/加速度含义未从截图确认。
