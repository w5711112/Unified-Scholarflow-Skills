- 原文件：屏幕截图 2026-08-02 002625.png。

- **用户个人学习重点**：整体流程感很高级；黑色流程箭头的弧度很好，且与大虚线边框的圆角程度协调；`Size of State Vector` 的表示方式值得学习；细长、会摆动的连续体结构也很美观；颜色组织不错，但用户随后明确本轮颜色不作好看色号参考。

### 2. 图本身表达什么

(a) 用静态平衡数据训练 equilibrium prior，再沿动态轨迹构造 prior-consistent residual target 并拟合 residual map，形成 Hybrid ID Rollout；(b) 给定输入序列，在 OOD 条件下迭代锚定更新、残差修正和反馈，生成多步预测并与真实状态计算 rollout error。连续体机械臂的 k、k+1、k+2 形态把状态演化落到物理对象。

### 3. 逐元素与连接核读

**(a) Training / Hybrid ID Rollout：**

- 左下 Robot Mechanics 用三根驱动/绳索 `u₁ u₂ u₃` 和细长连续体臂表示同一物理对象；向上 `Statics`、向右 `Dynamics` 两条箭头分流。
- 静态数据 `D₂` 用一张红—蓝薄矩阵表示：一侧标 Size of Input Vector，另一侧标 Size of State Vector，末端括号标 Equilibrium Sample Space。
- 动态数据 `D₁` 用多张平行薄片组成的矩阵堆表示：薄片数对应 `# of Trajectories`，单片两维标输入向量与状态向量，顶部括号标 Trajectory Size。
- Equilibrium Prior 容器内并列 Linear regression、Ridge regression、Multi-layered perceptron，并以曲面、胶囊形/核形图标和小网络图形承载差异；输出 `x_k^eq=P(u_k)`。
- 上方连续体臂以 k、k+1、k+2 三个形态排列，青色箭头表示时间推进；公式给出锚定更新。
- Residual Learning 容器内包含 residual target、feature lift、ridge regression 与 `R(z_k)`；公式和胶囊形示意共同说明残差拟合。

**(b) Hybrid OOD Rollout：**

- 顶部 `D_test` 同样用矩阵堆表达输入序列、状态向量和 trajectory size，与训练区共享矩阵语法。
- 大圆角虚线容器内，输入 `u_k` 进入锚定更新；`z_k` 进入 residual map；预测状态经两个乘/组合节点与延迟节点 `||` 形成循环。
- 右侧棕红虚线反馈把估计状态送回下一步；底部 `e_k` 与真实状态路径在乘/差节点汇合，caption 定义为 rollout error against ground truth。

**箭头/连线账本：**

- Robot Mechanics → D₂/D₁｜青色粗箭头｜Statics / Dynamics｜静态与动态数据来源。
- D₂ → Equilibrium Prior｜黑色水平箭头｜train｜训练 prior。
- Equilibrium Prior → 连续体臂序列｜黑色箭头｜`x_k^eq=P(u_k)`｜先验状态计算。
- D₁/臂序列 → residual target / Residual Learning｜多条黑色圆角连接｜`[u_k,x_{k+1}]`、`r_k*` 等就地标签｜残差样本构造。
- Training/ID 区 → OOD 区｜粗黑弧形连接跨越容器边缘｜预测/残差模型交接。
- OOD 内部实线回路与棕红虚线回路｜前者为当前步计算，后者为跨步反馈；精确定义以公式和 caption 为准。

**关系账本：**
