- **补充核读**：真正的关键不是“每个框都渐变”，而是两个大子系统背景分别采用低对比冷/暖渐变，内部节点大多是平坦浅色或同族阶梯。冷区显示色约 `#F4F8FB→#D0E2F1`，暖区约 `#FEF4F2→#F9DAC5`。

### 2. 图本身表达什么

上部 `(a)` 同时说明瞬时接触力网络 ICFN 与松弛补偿力网络 RCFN 如何从 ArUco 姿态和骨架温度输入得到瞬时力、松弛参数和有效交互力；下部 `(b)` 给 RGB/IR 多模态采样与两网络推理延迟，`(c)` 给 MCU、驱动、电机、加热膜、相机、Host PC 和 PID 的闭环部署。

### 3. 逐元素与连接核读

**逐元素账本：**

- `(a)` 左大域为冷蓝背景：最左是 ArUco pose、温度热图及输入向量，中间是 ICFN 逐层网络，右侧窄栏展开 residual block；底部输出 `Predict F_inst`。
- `(a)` 右大域为暖桃背景：右侧输入卡提供 pose 与平均温度，中间网络经 normalization、两路 ridge regression 输出 relaxation magnitude/time constant，再进入显式松弛公式。
- 蓝色线把 `F_inst` 与 `F_relax` 汇入圆形加法节点，右侧蓝紫箭头指向机械夹爪并标 `Effective interaction force F_eff`；红色小圆/文字标 grasp holding 条件。
- `(b)` 按 RGB Camera、IR Camera、Feature Construction、ICFN Inference、RCFN Inference 五条横向泳道排列帧、时间间隔和延迟，绿色/橙色箭头分别汇总 4.8 ms 与 4.94 ms。
- `(c)` 左侧 User Interface 向 MCU/Host PC 发送目标力和目标刚度/温度；MCU 驱动 motor/heating film，相机把 thermal/ArUco image 回传 Host PC，PID 与 ICFN/RCFN形成控制闭环。

**箭头/连线账本：**

- 输入特征 → ICFN/RCFN｜浅绿块箭头｜特征进入网络。
- ICFN 输出与 RCFN 输出 → 加法节点｜蓝色实线/弯线｜瞬时力与松弛补偿合成有效力。
- `(b)` 帧序列与竖线｜黑/彩色时间标记｜说明 33 ms、1.0 s、3.5 ms、1.3 ms、0.14 ms 等采样/推理时序。
- `(c)` 控制命令、驱动、相机反馈｜黑/蓝/红箭头与虚线｜区分控制、设备驱动和图像回传。

**关系账本：**

- `(a)` 给模型与物理方程，`(b)`证明在线执行节奏，`(c)`说明真实闭环落点；三者分别回答“怎么算、来不来得及、部署在哪里”。
- 冷色绑定瞬时感知/力估计，暖色绑定热松弛补偿，蓝色合力链跨域连接；颜色按物理职责成片分布，不按层数轮换。

### 4. 全局构图与阅读路径

上部占约三分之二高度并分冷暖两大域，是视觉锚；下部左宽右窄分别放时序和系统架构。三块间用白色窄沟槽分离，内部边距一致。所谓“没有留白”准确说是**没有无意义空洞**：仍保留模块内边距、箭头通道和面板沟槽。

### 5. 局部视觉语法

大域背景用低对比纵向/斜向渐变，节点用浅紫、浅蓝、青、浅黄、浅桃的平坦阶梯；粗黑边只用于网络主容器，次节点用较细边。蓝色输出线和加法圆建立跨域主轴，实物图只出现在输入和物理输出端。统一圆角和轻投影保持柔和而不 UI 化。

### 6. 为什么有效

- 信息密度由三层证据职责产生，不是装饰堆叠。
- 大域渐变先区分两个物理子系统，内部颜色再按网络深度/功能细分，形成“区域→模块→节点”的三级层级。
- 模块尺寸与信息量对应：主网络最大，residual 细节窄，公式和加法节点贴近真正汇合位置。
- 照片、热图、公式、时序和硬件图各自只出现一次且都有落点，避免重复素材。
- 冷暖背景在靠近白色顶部时很轻，不压黑字；下方略深，帮助托住流程和机械输出。

### 7. 可以吸收的绘图知识

- 固化“语义分区的低对比渐变底”和“模型内部→在线时序→闭环部署”的紧凑主图合同。
- 大范围渐变只绑定正式子系统；内部卡片保持平坦，不给每个框加渐变/阴影。
- 先按信息职责分配面积，再消除空洞；不能把“无留白”误解为零边距。
- 适合矢量软件/PowerPoint/Visio 做总排版，网络块和时序可由 SVG/Python 辅助生成；最终统一圆角、线宽、字体与箭头端点。

### 8. 不足、误读风险与不应照搬

顶部网络文字在单栏缩放后可能偏小；局部同时存在黑、蓝、红箭头，需要图例/caption 明确。暖区的多个桃色阶不能被当作连续量。不要照搬所有内部网络层，也不要用强渐变、发光或重阴影模拟其层次。

### 9. 本图最值得学习什么（收录理由）

它把高密度机制、时间证据与闭环系统压进一张主图，却仍靠区域语义、尺度层级和统一曲率保持温和清楚；是“规整、高级、充实但不花哨”的重点参考。

### 10. 证据边界

背景渐变的源色/alpha、内部节点精确色号、原始字体、网络维度全部含义、时序是否为均值以及作者使用的软件未从截图完全确认；记录的是最终像素与可见结构。
