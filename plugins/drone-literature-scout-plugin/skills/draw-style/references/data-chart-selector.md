# 数据图选择器：先读数据，再选图，再选软件

## 1. 目标与输出

本选择器服务于真实数据图、统计图、算法空间结果和照片—数据混合证据图。质量顺序固定为：**准确、实用、高级、克制美观、排版合理**。高级感来自证据层次、视觉秩序和恰当图型，不来自图标堆叠、无意义渐变、装饰性 3D 或罕见图型本身。

默认决策链是：

`数据语义体检 → 候选图型短名单 → 人工定型门 → WPS / Python / MATLAB / 逐面板混合路线 → 统计与终稿验收`

如果用户尚未指定图型，先给 **2—4 个**真正合适的候选，逐项说明读者问题、优点、缺点、误读风险和生产软件，由**用户作最终选择**。如果用户已明确指定图型且统计语义成立，直接执行，不重复询问；若指定图型会误导，则先解释问题并给最小替代方案。

## 2. 数据语义体检

选图前先回答，缺失项不得靠视觉补全：

- **读者问题**：比较、排名、趋势、分布、相关、构成、流动、阈值、事件、空间关系还是机制差异？
- **变量类型**：类别、有序类别、连续数值、时间、角度、比例、矩阵、图结构、三维坐标或图像区域。
- **观测结构**：独立还是配对；单层还是嵌套；是否有重复测量、随机种子、任务、被试或环境层级。
- **样本与密度**：样本数、离群点、多峰性、偏态、零膨胀、长尾、缺失和不规则采样。
- **估计与区间**：mean/median/quantile、SD/SE/CI/range、样本量和构造方法。
- **比较公平性**：共享轴域、尺度、基线、归一化、排序、时间支持和有效样本是否一致。
- **连续与离散**：是否真的存在连续关系；类别档位不能用过度平滑制造连续函数。
- **空间含义**：第三维是否承载高度、体积、遮挡、穿越或连续标量；否则保持 2D。
- **交付约束**：论文/PPT/Obsidian、最终宽度、黑白打印、色盲、WPS 可编辑性、脚本复现和源数据权限。

先写一句单一主张：`读者看完这张图，必须能判断______。` 如果一句话中出现两个互不依赖的问题，优先拆成 small multiples 或主图＋解释面板。

## 3. 按读者问题生成候选

下表是候选发生器，不是强制菜单。只有数据满足适用条件时才进入短名单。

| 读者问题与数据线索 | 首选候选 | 可选替代 | 优点 | 缺点与误读风险 | 常用路线 |
|---|---|---|---|---|---|
| 少量离散类别的大小比较 | 排序点图、lollipop、横向条形 | 分组柱形、slopegraph | 基线清楚、直接标签容易、占用紧凑 | 柱形会强调面积；类别过多时图例膨胀 | WPS；圆角或复杂标注用 Python |
| 多方法×少量条件 | 分组点区间图、分组柱/条 | small-multiple 折线、热图 | 比较路径直接，区间可见 | 组数过多会拥挤；误差定义不能省略 | WPS / Python |
| 有序或连续自变量的变化 | 折线＋实际采样点 | slopegraph、面积图、fan chart | 趋势和拐点清楚 | 平滑线可能伪造观测；面积会强化大小 | WPS；复杂区间和事件用 Python |
| 两条序列的差距如何变化 | 同轴折线＋差值解释层 | 差值单独小图、ratio 曲线 | 直接回答 gap 何时扩大或缩小 | 两系列必须共享 x 支持；大面积填充会夸大差异 | Python；简单同轴面积可用 WPS |
| 单变量分布 | 原始点＋box、直方图/ECDF | violin、raincloud、ridgeline | 样本、中心和尾部可以分层阅读 | KDE/violin 受带宽影响；少样本会伪造平滑精度 | WPS box/hist；高级分布用 Python |
| 配对前后变化 | paired dot/slopegraph | paired box＋连线、Bland–Altman | 保留个体方向与幅度 | 线太多会缠绕；不能丢失配对身份 | WPS / Python |
| 两变量关系或权衡 | scatter＋趋势/区间 | bubble、hexbin、density contour | 保留原始样本结构 | 气泡面积容易误读；趋势线不等于因果 | WPS scatter/bubble；密度与避让用 Python |
| 高维表示的训练/未见条件是否邻近或分离 | **t-SNE 嵌入投影**＋身份 marker | UMAP、PCA、定量邻域指标 | 可保留大量样本并用五角星突出少量未见条件 | 轴无物理单位、全局距离和簇面积不可直接解释；结果依赖 seed/perplexity | Python |
| 三个以上同向归一指标 | 雷达、平行坐标 | small-multiple dot plot | 雷达给整体轮廓；平行坐标保留样本路径 | 雷达面积易误读、轴顺序敏感；必须统一方向与尺度 | WPS radar；复杂标签用 Python |
| 部分—整体构成 | 100% 堆积条、普通堆积条 | doughnut/pie、treemap、sunburst | 堆积图可比较结构；层级图可显示嵌套 | 饼图难比较近似扇区；3D 饼图扭曲角度 | WPS；复杂层级用 Python |
| 流量、迁移或阶段去向 | Sankey/alluvial | waterfall、funnel、阶段矩阵 | 能追踪来源和去向 | 线宽必须对应真实量；节点过多会花哨 | Python；waterfall/funnel 可用 WPS |
| 二维类别矩阵或大量组合 | heatmap＋直接数值 | dot matrix、small multiples | 高密度且容易找模式 | 色阶会隐藏绝对差；必须给色条和缺失值编码 | WPS 基础热图 / Python |
| 两连续变量决定一个标量 | scatter＋拟合、filled contour | pseudocolor、2D 响应面、3D surface | 等值线适合读区域；3D 适合读空间形状 | 插值面不等于实测；3D 透视不适合精确比较 | Python / MATLAB |
| 候选位置能让哪些空间区域满足阈值 | **覆盖场＋阈值边界** | heatmap＋contour、binary coverage mask | 连续场、候选位置和可保证区域同时可读；多候选可直接对照 | 阈值必须正式定义；跨面板必须共享轴域、归一化与**共享色条**，不能各自拉伸颜色 | Python / MATLAB |
| 值函数/屏障场怎样形成安全集合与回归方向 | **安全集场＋零水平边界＋梯度箭头** | 2D contour＋少量向量、3D bounded hill | 同时看到场值、集合边界、局部方向与专家/目标状态 | 梯度必须来自场；投影视图需共享色条；3D 透视不适合精确边界比较 | Python / MATLAB |
| 约束、目标等值线与算法迭代 | 共享坐标域的算法轨迹比较 | 轨迹 small multiples、phase portrait | 同一问题域内直接看路径、切换与极限点 | 图例与编码多；每一层必须有算法语义 | Python / MATLAB |
| 事件、阈值和制度切换 | 时间线＋事件窗/参考线 | event plot、step plot、stock/OHLC | 事件与响应可对齐 | 背景窗必须有正式定义，不能只填空白 | WPS 基础线图；复杂事件用 Python |
| 排程、资源占用和阶段持续 | Gantt、区间条 | timeline、waterfall | 开始、结束与重叠直接可读 | 任务太多时标签拥挤 | WPS / Python |
| 三维位置、速度或占据 | 3D scatter/trajectory、surface、体/切片 | 2D 正交投影＋量化图 | 真实空间穿越、遮挡和高度可见 | 相机和比例会误导；必须配轴、色条或正交证据 | MATLAB / Python |
| 实物场景与数据事件一一对应 | 实物场景—定量诊断映射 | 照片＋局部数据 inset、编号对照 | 把事件、位置和数值组成证据链 | 对应关系不真实时会制造因果；引线容易交叉 | Python/MATLAB 出图＋矢量排版 |

### 3.1 不为了“丰富”而误选图型

- 数据只有几个确定值时，不用 violin、KDE 或复杂曲面制造不存在的分布。
- 有原始样本时，优先让点、轨迹、区间或矩阵承担信息密度；不靠装饰图标填满画面。
- 稀疏数据图显得空，先检查轴域、排序、直接标注、条宽、点大小和解释层是否合理，再考虑换图型。
- 图型必须增加可回答的问题；只是“没见过”不能成为选择理由。

## 4. 人工定型门

给用户的短名单使用下列紧凑模板：

```text
数据与主张：
候选 A｜图型｜最适合回答什么｜优点｜缺点/误读风险｜推荐软件
候选 B｜图型｜最适合回答什么｜优点｜缺点/误读风险｜推荐软件
候选 C｜图型｜仅在什么条件下优于 A/B
我的推荐：A，因为______。
需要用户决定：A / B / C，或指定更看重精确读数、分布细节、可编辑性、空间直觉。
```

短名单只给统计上成立的选项，不把明显较差的图型凑数。推荐项放第一，并说明牺牲了什么。

## 5. 软件路线

### 5.1 WPS：简单、可编辑、快速

当 WPS 能完成且不牺牲统计准确性时优先使用。其适用大类包括：

- 柱形：簇状、堆积、百分比堆积；
- 折线：普通、堆积、百分比堆积；
- 组合图；
- 饼图：普通、三维、复合饼、复合条饼；三维仅为兼容旧稿，不作为新图默认；
- 圆环图；
- 条形：簇状、堆积、百分比堆积；
- 面积：普通、堆积、百分比堆积；
- 散点：纯散点、平滑线、直线、气泡；
- 股价图；
- 雷达：带标记、填充；
- 树状图、旭日图；
- 直方图、Pareto；
- 箱线图、瀑布图、漏斗图。

WPS 终稿需保留可编辑数据源，核验“编辑数据”仍能打开正确表格。优先用直接标签、适当误差棒、浅网格和统一字体；不要依赖默认彩虹色、立体阴影或自动平滑。

### 5.2 Python：高级二维统计与复杂布局

适用于：violin/raincloud/KDE/ECDF、密集原始点、复杂 small multiples、非规则曲线、quantile/fan band、局部放大、标签避让、图标化散点、差值解释层、共享坐标域的算法轨迹、复杂热图/等值线和实物—数据复合排版。

必须保留输入数据、脚本、依赖和导出参数。优先导出 SVG/PDF 或高分辨率 PNG；字体、线宽和标记按最终嵌入宽度检查，而不是只看开发窗口。

### 5.3 MATLAB：2.5D/3D 与算法空间效果

适用于：规则/非规则曲面、空间轨迹、体数据切片、工程场、速度着色、可行域、三维不确定性和算法地形。第三维必须承载真实变量或空间事实；否则用 2D heatmap/contour 更准确。

固定 `view`、轴域、`box aspect`、投影、色条规范化和插值边界。多个方法比较时共享相机和尺度；实测点与插值面分层显示。

### 5.4 逐面板混合路线

复合图允许逐面板选择软件，例如：WPS 可编辑柱图＋Python 分布图＋MATLAB 空间轨迹。统一项由 draw-style 负责：字体角色、字号、色彩语义、线宽、面板字母、外边距、图例职责、导出格式和最终阅读顺序。

## 6. 证据层与高级感

图表丰满优先来自以下证据层，按需要选择，不能全部机械叠加：

1. 原始点、样本线或真实轨迹；
2. 中心趋势、拟合或插值解释；
3. 已定义的 SD/SE/CI/quantile/range；
4. 参考线、阈值、可行域或共同基线；
5. 事件点、模式切换或极值；
6. 直接数值、局部公式或简短解释；
7. inset、正交视图或实物场景对应。

每增加一层都要能完成句子：`它编码______，帮助读者判断______。` 无法完成就删除。颜色、线型、形状和透明度不能重复编码互相冲突的变量。

## 7. 与领域写作 Skill 的协作

当任务具有负责数据与论文交付的领域 Skill 时，在生成候选图型前读取其当前合同。该 Skill 应从用户配置或当前工作区发现，不能把固定盘符作为唯一依赖。

- 领域 Skill 是数据血缘、指标、统计含义、人工选定方法和发布状态的负责人。
- draw-style 是候选图型、视觉编码、颜色字体、布局密度、生产视觉实现和终稿验收的负责人。
- 若领域 Skill 要求使用可编辑原生图表，该要求在当前场景中属于路由约束。`draw-style` 负责判断原生图型是否能忠实表达数据；不能忠实表达时，应说明替代工具与原因。
- 普通科研论文、PPT 和 Obsidian 数据图仍可独立使用本选择器。

## 8. 终稿验收

- 结论可由图中真实数据支持，没有把相关画成因果、把插值画成观测或把范围画成 CI。
- 轴、单位、尺度、方向、样本量、统计单位和区间定义完整。
- 比较面板共享必要的轴域、基线、相机和色条；不以不同缩放制造优势。
- 数据主体占据有效绘图区，图例不覆盖关键数据，留白承担分区或阅读通道职责。
- 坐标、数字、图例和直接标注在最终尺寸可读；点、端帽和虚线不会缩没。
- 颜色在灰度和常见色觉条件下仍有形状、线型或直接标签备份。
- WPS 图保留可编辑数据，Python/MATLAB 图保留脚本与输入，混合图记录每个面板来源。
- 美观来自对齐、层级、克制色彩和证据密度；不靠无意义渐变、厚重阴影、伪 3D 或素材堆叠。
