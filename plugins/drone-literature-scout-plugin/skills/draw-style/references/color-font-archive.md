# Draw-style 色号与字体历史档案

## 1. 档案边界

本文件保存已核对的截图显示色、候选源色、近邻色和字形取证结果，仅用于**精确复现、来源追溯或近色比对**，**不作为新图默认**。新图的常规选择入口是 `visual-language.md` 中的“六个核心色族＋四条连续数据色阶＋三套命名模板”。

色号判读分四层：

1. **主色**：大面积平坦像素，可作为源色候选。
2. **显示色阶**：透明填充、发光、叠加或截图压缩造成的浅深变化。
3. **抗锯齿近邻色**：只出现在边缘的少量过渡像素，不扩展成新调色板。
4. **源色与 alpha**：截图只提供最终显示像素，不能唯一反推作者源色和 alpha。

因此，不把显示色阶当作离散类别色，也不把抗锯齿色当作新的选色依据。

## 3. 历史字形取证

- RSS2026_060 的 `dataset`、`HDBSCAN` 与 **Comic Sans MS Regular** 高度相似，`RNN` 更接近 **Comic Sans MS Italic**。PNG 无字体元数据，只能记为强匹配候选。
- RSS2026_061、062 的图内标签与 RSS2026_063 的任务指令卡延续圆润手写字形，可以 **Comic Neue** 作为更克制的跨平台候选。
- RSS2026_070 的大号坐标数字更接近 Matplotlib 常见的 **DejaVu Sans / Arial / Helvetica** 家族，但 PNG 无法区分具体字体文件。
- RSS2026_086、087 的 `Vectorized QMDP Planning`、`Scenario Sampling`、`Two-stage SIMD collision checking` 与图内短标签延续圆润手写感，外观接近 **Comic Sans MS / Comic Neue**；适合短标题与箭头标签，不扩展到数学式和长 caption。
- 任何字体候选都必须在终稿尺寸下核对 `0/6/8/9`、负号、括号、单位、大写缩写和斜体变量；截图相似不等于作者原字体事实。
