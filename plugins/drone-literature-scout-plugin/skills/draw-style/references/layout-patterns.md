# 布局、视角与空间表达模式

## 1. 先选择表达维度

- **2D**：平面拓扑、栅格搜索、二维曲线、时间序列、算法状态图和无需高度解释的数据图。
- **2.5D**：层级、深度提示、堆叠模块或轻微透视能帮助阅读，但不要求精确体积和遮挡关系。
- **3D**：对象涉及体积、上下高度、遮挡或空间穿越关系，且这些关系属于原理本身。

选择目标是视觉上易懂且准确。2D 已能完整解释时不强行立体化；3D 必须承载空间事实，不是装饰性 3D。

## 2. 论文几何与曲线保真

- 先读取本地原文依据，论文怎样定义就怎样画。矩形、类长方体、一般多边形与凸多面体不得互换；直线、折线、B-spline 与自由曲线不得互换。
- 透视图可以出现斜边，但不能改变面、边、平行、垂直、包含和连接关系。
- 俯视宽度和侧视高度不能混成一个无视图定义的二维形状。
- 曲线图核对阶数/次数、节点约定、分段凸包、单控制点局部支撑、连续性和边界条件。
- 符号、下标、数量、维度、箭头和采样区间并入现有提示词预检和七项验收，不增加第二次审图或重复扫描。

## 3. 主图、正交视图和局部放大

- 需要空间直觉与平面核验时，以三维主图建立体积、遮挡和穿越关系，以正交俯视图核对平面几何；每个面板承担不同核对职责。
- **3D 主景—正交核验—同刻度实景**适合空间轨迹同时受体积障碍、平面绕行和传感器观测影响的实验：3D 主景解释高度、障碍体与不确定性管，2D/正交图核对平面位置，实景或相机条带说明同一状态在传感器中的外观。三层不能重复同一问题，也不能让照片只充当装饰。
- 在上述组合中建立**跨表示状态锚**：复用同一组时间、阶段编号、起终点或关键事件，例如 `t=0/10/16/24/28/34` 同时落在 3D 路径、2D 投影和实景帧。锚点只表示身份对应，不将投影或截图误画成因果流；各表示中的颜色、对象和时间必须一一可核。
- 有高度的走廊体不能压成一条二维带状图。俯视图只说明横向/平面关系，侧视或 3D 图说明高度。
- 局部放大使用清楚的连接标记，保持对象颜色、方向和尺度语义一致；不得把局部图旋转到无法对应主图。
- 关键接触、碰撞或微观更新采用 `原位框选 → 虚线引线 → 极简放大窗`：原位框确定位置，引线只表达对应，放大窗只保留决定更新的对象与方向量；不要把整个主场景重复一遍。

## 4. 常用布局家族

- **单场景直接标注**：少对象、空间关系明确，标签围绕对象分布。
- **左右对照**：共享条件置于顶部或中轴，只改变比较因素；左右宽度、尺度和标签层级一致。
- **阶段序列**：按时间或算法更新从左到右/上到下编号，状态差异直接落在对象上。
- **系统流程＋物理落点**：流程框只保留必要模块，最终输出指向真实设备、环境或行为结果。
- **主图＋机制 inset**：主图给全局关系，圆形或矩形 inset 解释微观机制、局部几何或统计细节。
- **多轨并行**：训练/部署、感知/规划/控制等并行链使用分区底色和明确汇合点，不让跨区箭头交叉。
- **混合证据总览**：按 `集合 → 过程 → 数据结果` 组织属性集合、运行机制和量化表现；三区可以使用 Venn、阶段矩阵和数据图等不同图形语法，但共享底板、字体层级、边距和阅读方向。
- **渐进灰阶阶段底板**：当 3—4 个阶段按单向流程推进且内部已经有彩色对象时，用从近白到中灰的连续明度分区托住阶段，不再给每阶段增加新色相。RSS2026_093 的显示灰阶为 `#F9F9F9 → #F1F1F1 → #D8D8D8 → #BEBEBE`；明暗必须绑定时间、搜索深度或阶段推进，并保证最深区的文字/实物仍有足够对比。

### 4.1 紧凑证据板、共享几何与局部判别

- **紧凑分区证据板**：用一个完整外轮廓收束 2—3 个职责不同的色块区域，内部允许“左侧大区＋右侧上下分区”等不等面积拼接。色块绑定阶段或证据类别，角落使用低对比 A/B/C 地址标签便于 caption 与截图定位。先保留阅读通道，再消除无意义空洞；不能把公式、照片和文字平均塞满每格。
- 渐进灰阶阶段底板的阶段交界优先使用**圆角重叠接缝**：后一阶段的左缘以统一半径覆盖前一阶段，形成连续带状过渡；接缝只表达阶段边界，不添加伪 3D 厚度或阴影。标题基线与顶部曲率统一，内部彩色对象不得跨接缝造成阶段归属歧义。
- **共享几何逐层揭示**：多面板固定对象轮廓、坐标、比例和视角，每一面板只增加一个层，如网格编号→编码子集→查询距离→分类区域。相同边、点、符号跨面板保持身份；新颜色只在其语义首次出现时加入。它强化 M1 的同构比较，但适用于空间/拓扑解释而不只适用于时间序列。
- **圆形局部向量判别窗**不是普通像素放大，而是从主几何抽取同一接触或局部区域，在圆盘中保留边界扇区、法向、梯度、夹角和判定结果。多个圆窗共享尺度和方向，并以 `filtered / valid` 等直接标签组成小型对照；若发生旋转或归一化，必须标明。
- 圆形窗只在局部角度、法向或相位关系本身是判断依据时使用。普通纹理、曲线局部误差仍用矩形 inset；不能为了“显微镜感”把无关区域裁成圆形。

## 5. 精华母版的布局实施合同

- **M1 实施合同**：阶段序列共享对象几何、场景、基线、尺度和标签锚点；每个面板只改变一个核心状态。时间或条件沿单一方向排列，参数贴近对应对象；连续阶段可用横向括号合并，不另加流程框。
- **M4 局部证据合同**：先判断 inset 是**纯局部放大**，还是保持变量不变但发生**参数/尺度切换**。前者保持方向、比例语义和对象身份；后者必须在 inset 标题中直接写出改变的参数。统一采用 `原位框选 → 短引线 → 同向局部窗`，引线不跨越主数据。
- **M8 空间事实合同**：3D 比较固定三轴、轴域、box aspect、相机、投影和遮挡规则；当透视不利于精确核对时，增加一个正交视图或二维量化图，而不是任意旋转到“看起来更清楚”。

## 6. 紧凑而均匀

先定语义再定画布，并裁切到语义边界。主体占画布的主要区域，但**不使用固定内容占比或边距百分比**；同级区块既不紧贴也不出现无意义大空洞。密集面板降低装饰、缩短连接，不能通过缩小关键文字来硬塞。
