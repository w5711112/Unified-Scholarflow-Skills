# PPT 图模式

## 目标

PPT 图服务于远距离、短停留阅读：一页只突出一个结论，图形先于文字被看懂。它不是把论文主图原样缩到幻灯片。

## 规则

- 保留 3–7 个主要视觉对象；复杂方法拆成跨页递进，而不是在一页缩小所有模块。
- 标题承担结论，图内标签只解释对象与关系；正文式 caption 通常移到演讲备注。
- 使用强视觉中心、明确进入点和单向阅读顺序；次要上下文降为浅灰。
- 关键数字、方向或对比结论直接贴近对象，避免依赖图例来回查找。
- 字号和线宽按投影距离验收；颜色对比高于 Obsidian/论文，但仍保持科研克制。
- 可用适量真实照片、设备剪影或场景图建立直觉，但必须与示意编码风格统一。

## 不适用

需要逐公式核验、多个实验条件和完整不确定性说明的内容，应转为论文图或拆页，不在一张 PPT 图中压缩。
