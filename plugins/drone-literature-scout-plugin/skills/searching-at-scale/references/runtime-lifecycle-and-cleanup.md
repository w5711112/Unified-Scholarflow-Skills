# 运行接口、中间产物与清理合同

只在建立临时运行、恢复、最终清理或校验产物时加载。本合同持有运行时文件、确定性脚本状态边界和镜像交付要求；不得用它替代来源、证据或报告合同。

## 空闲零常驻与任务专属路径

- 通用搜索遵循**空闲零常驻**：不拥有后台服务、容器、TCP 端口或常驻索引。用户批准的 Edge Native Messaging 是唯一例外，只在 Edge 运行时保留一个轻量 C# Native Host，Edge 关闭即退出。
- 不自动启动 Docker Desktop，不创建持久 volume。Docker/镜像不可用只令临时 SearXNG `unavailable`，其他后端继续。
- `%LOCALAPPDATA%\searching-at-scale` 只可保留经版本和哈希验证的 DuckDB 依赖、扩展和 Common Crawl manifest 缓存；这些缓存不启动进程，也不是工作文档或任务状态。
- 大规模运行只在调用方授权的任务临时目录创建任务专属 SQLite 与有界流式 NDJSON；保存最小 URL 账本、去重键、来源、游标和状态，不把 URL 池塞入上下文或状态 JSON，不保存无关全文、截图或秘密。
- 创建、读取或清理前解析并验证绝对路径，确认它位于任务专属临时目录；禁止对宽泛路径递归删除。

## 脚本状态所有权

- `scripts/market_scheduler.py` 是唯一可读写调用方显式给出的任务专属状态路径的脚本；使用临时文件+原子替换保存 JSON，SQLite 以单事务、外键、幂等批次 ID 提交且不使用 WAL。
- 除 `scripts/market_scheduler.py` 外，其他确定性脚本只用函数导入或**标准输入/输出**承接业务数据，**不得读写任务状态文件**或 URL 池。
- `scripts/common_crawl_url_index.py` 与 `scripts/duckdb_runtime.py` 只在 Vault 外管理已验证依赖、manifest 和本轮批次目录；不得把缓存当任务状态。
- `scripts/backend_runner.py` 的每任务事件流写入有界 NDJSON 卷轴，每行不超过 64 KiB；完整关闭后主线程流式提交 SQLite。调度结果只返回计数、时间、轮次和遥测，不返回 URL 列表。
- 失败批次不得留下半事务；恢复重放已提交但未写入状态 JSON 的终端摘要，不清零纯发现时间、累计 URL、已尝试维度、失败审计或跨轮并集。

## 统一清理与产物白名单

1. 成功、失败和中断走同一精确清理路径：只停止本轮记录的容器 ID 或 PID 树，关闭连接，删除本任务卷轴/批次目录，然后验证不存在。
2. 临时 SearXNG 不保留容器或 volume；一次性 Node、浏览器自动化、任务卷轴和监听端口不得残留。Edge 自身按需启动的 Native Host 随端口退出。
3. 可复用的验证依赖与 manifest 缓存留在 Vault 外。项目内默认不允许新增文件；事故处理只允许项目守卫指定事故库，用户明确要求保存时只允许约定的一个 Markdown。
4. 搜索前后比较工作区文件清单；URL 池、页面缓存、正文、临时 CSV/JSON、截图、爬取数据库、任务队列和筛选缓存均不在白名单。出现额外文件即验证失败，先记录事故再精确清理或换路。
5. 清理失败必须披露精确残留路径。Fess、Zoekt 等持久索引只有用户明确批准建设可复用基础设施时才可创建，不能替代一次性账本。

## 最终验证与镜像

- `RUN_ACCEPTANCE` 只消费一次新鲜检查：运行状态合法、来源/覆盖/证据/报告对象一致、必需测试通过、清理白名单通过、无未披露阻塞。
- 中途已核验对象只在输入指纹未变时复用；来源内容、范围、运行 ID、状态、账本摘要、报告数据或工作区清单变化时，只刷新受影响对象及下游。
- 修改入口或直接参考后，通过治理插件的 `sync-guides research.searching-at-scale` 刷新 `Skill完整指南/research/searching-at-scale-完整指南.md`，再运行来源漂移与渲染漂移审计。中央指南只用于阅读，不能反向覆盖 canonical。
